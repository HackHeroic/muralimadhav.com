# muralimadhav.com

This is my personal portfolio website built with Next.js, showcasing my projects, achievements, and experience in software engineering, AI, and machine learning.

## 🚀 Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI, shadcn/ui
- **Deployment**: Vercel
- **Language**: TypeScript

## 📋 Features

- Responsive design with dark/light mode support
- Showcase of projects with GitHub links
- Work experience and education timeline
- Research publications and achievements
- Hackathon achievements
- Skills and technologies
- Contact information with social links

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 📝 Customization

All personal data is stored in `src/data/resume.tsx`. Update the following sections:

- Personal information (name, email, location)
- Work experience
- Education
- Projects
- Skills
- Achievements
- Social media links
